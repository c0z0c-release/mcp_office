# MCP Office

AI 클라이언트(Claude Desktop, Claude Code 등)가 **설치된 데스크톱 오피스 앱을 직접 조작**하게 해 주는 MCP 서버 모음입니다.
Microsoft Office(Excel/Word/PowerPoint/Outlook/OneNote/Visio)와 한컴오피스 **한글(HWP)** 을 지원합니다.
파일을 읽고 새로 쓰는 방식이 아니라, 실행 중인 앱에 연결해 보고 있는 문서를 그 자리에서 편집합니다.

## 특징

- **열려 있는 문서를 그대로 편집**: 사용자가 화면에 띄워 둔 통합 문서·문서·프레젠테이션에 바로 반영됩니다(한글은 예외: 아래 "한글(HWP) 참고"). 파일을 내려받고 다시 올리거나 덮어쓸 필요가 없고, 결과를 화면에서 바로 확인하며 이어서 고칠 수 있습니다.
- **앱의 모든 기능 사용**: 서식, 차트, 피벗, 표, 도형, 수식, 변경 내용 추적 등 앱이 제공하는 기능을 그대로 쓸 수 있습니다. 용도별 도구로 부족하면 `com_*` 도구로 앱의 기능에 직접 접근할 수 있습니다.
- **저장·닫기·메일 초안도 도구로 제공**: 문서 저장과 닫기는 별도 도구(`*_save_*`, `*_close_*`)로 실행합니다. Outlook 은 메일 초안을 임시 보관함에 저장하고, 사용자가 Outlook 에서 확인한 뒤 전송합니다.
- **설치 한 번으로 등록**: 설치기가 서버 8개를 설치하고 AI 클라이언트 설정에 등록합니다. 별도 런타임 없이 단일 exe 로 동작합니다.

## 서버

| 서버 | 대상 | 주요 기능 |
| --- | --- | --- |
| excel | Excel | 셀·표 읽기/쓰기, 서식, 차트, 피벗, 조건부 서식, PDF/이미지 내보내기 |
| word | Word | 문단·표·머리글/바닥글, 스타일, 주석, 필드, PDF 내보내기 |
| powerpoint | PowerPoint | 슬라이드·도형·표·차트, 애니메이션, 노트, 테마, 내보내기 |
| visio | Visio | 도형·스텐실 기반 다이어그램 |
| outlook | Outlook(클래식) | 메일 조회, 초안 작성, 일정, 작업 |
| outlook_todo | Outlook 작업 | 할 일 목록, 작업 생성·완료, 플래그 메일 |
| onenote | OneNote | 노트북·섹션·페이지 편집, 표, 도형, 순서도 |
| hwp | 한컴오피스 한글 | 문단·제목·표·그림·도형·수식, 필드(누름틀), 각주·링크·책갈피, 머리말/꼬리말, 쪽 설정, PDF 내보내기 |

각 서버는 `api_guide` 도구로 작업별 사용법(레시피)과 도구 목록을 알려 주므로, AI 가 처음에 이 도구를 호출하면 올바르게 사용할 수 있습니다.

## 한글(HWP) 참고

- 한글은 사용자가 직접 연 창에 COM 으로 연결할 수 없어, 서버가 **자기 한글 창을 따로 띄워** 문서를 엽니다. 편집한 문서는 `hwp_save_document` 로 저장합니다.
- 파일 접근 승인 질의는 승인 모듈이, 메시지 상자는 서버가 자동으로 처리합니다.
- 한글 자동화가 지원하지 않는 기능(변경 내용 추적, 도형 묶기·정렬, 캡션, 목차, 상호 참조, 다단, docx/odt/HTML 가져오기·내보내기)은 도구로 제공하지 않습니다.
- 도구가 한글의 성공/실패 반환값을 믿지 않고 문서를 다시 읽어 결과를 확인하며, `hwp_export_pdf` 로 모양을 눈으로 확인하도록 안내합니다.

## 요구 사항

- Windows 와 해당 데스크톱 앱(Microsoft Office 또는 한컴오피스 한글)(Microsoft 365 Apps / Office 2024 기준). 앱이 설치되어 있지 않으면 `APP_NOT_INSTALLED` 오류로 알려 줍니다.
- Outlook 은 **클래식 Outlook** 이 필요합니다(새 Outlook 은 COM 을 지원하지 않습니다).
- 서버와 Office 앱은 **같은 권한 수준**으로 실행되어야 합니다. 한쪽만 관리자 권한이면 연결되지 않습니다.

## 지원 Office 버전

최신 데스크톱 Office(Microsoft 365 Apps, COM 16.0)를 기준으로 만들었고, 버전을 이유로 기능을 막지 않습니다.

| 구분 | 버전 | 상태 |
| --- | --- | --- |
| **테스트한 버전** | Microsoft 365 Apps `16.0.20527.20150` (Excel, Word, PowerPoint, Outlook, OneNote, Visio 모두 동일) | 검증됨 |
| **테스트한 버전(한글)** | 한컴오피스 2020 (한글 11.x). 다른 버전은 COM(`HWPFrame.HwpObject`)이 연결되면 쓰고 결과에 호환 안내를 붙임 | 검증됨(2020만) |
| 예상 가능 최저 버전 | **Office 2016** (COM 16.0) — Office 2019 / 2021 / 2024 포함 | **미검증(이론상)** |
| Office 2013 이하 | 연결 시도는 막지 않으나 보장하지 않음 | 미검증 |

- Microsoft 365 외의 버전은 개발 환경에 없어 직접 시험하지 못했습니다. 공식 문서의 적용 버전 표기를 근거로 한 **이론상의 추정**입니다.
- Office 2016 은 `Office16` 폴더와 COM 16.0 을 쓰므로 같은 방식으로 연결됩니다. 다만 2016 에 없는 기능은 아래처럼 동작합니다.

| 기능 | 필요한 버전 | 구버전에서의 동작 |
| --- | --- | --- |
| Excel 동적 배열 수식(`FILTER`, `SORT`, `Formula2`) | Excel 2021 / Microsoft 365 | 일반 수식(`Formula`)으로 대신 기록 (표 열 수식 포함) |
| Excel 스레드 댓글 | Microsoft 365 | 오류와 함께 메모(`kind='note'`) 사용 안내 |
| 그 밖에 구버전에 없는 멤버 | 기능마다 다름 | `ok:false` 오류와 `compat` 안내(서버는 계속 동작, 재시도 가능), `com_*` 도구로 우회 |

- 구버전에서 도구가 실패하면 서버가 종료되지 않고 `ok:false` 와 함께 `compat` 안내를 돌려주므로, AI 가 사용자에게 버전 문제임을 알려 줍니다.
- Office 2016 은 Microsoft 의 지원이 2025년 10월에 종료되었습니다.
- OneNote 는 데스크톱 앱(OneNote 2016 이상)이 필요하고, Microsoft Store 의 "OneNote for Windows 10"은 지원하지 않습니다. Outlook 은 클래식 Outlook 만 지원합니다.

## 설치

릴리스의 `mcp_office.exe` 를 실행합니다(서버 8개 내장). 설치 중에는 Claude Desktop 을 **먼저 종료**하세요. 켜 둔 채 설치하면 앱이 설정 파일을 다시 써서 방금 등록한 서버가 사라질 수 있습니다. 설치 뒤에는 AI 클라이언트를 다시 시작해야 새 서버가 보입니다. 서버 exe 는 `release\<버전>\<서버>\` 에도 있습니다.
